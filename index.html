03   FAQ

Questions?
We've got answers.

Will my existing tracker data be lost?

No. The original tracker is kept as tracker.html and continues using the same JavaScript and localStorage system.

Can I use this on mobile?

Yes. The landing page is responsive and the existing tracker remains usable on phone screens.

Where is my progress saved?

The tracker uses browser localStorage, so your saved data stays on that device/browser unless you clear site data.

What is inside the tracker?

Daily logs, subject-wise work, DPP/PYQ tracking, syllabus tracker, themes, TODO, focus mode, weekly report and PDF/backup features from your original script.
