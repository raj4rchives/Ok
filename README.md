# JEE Syllabus Tracker

Use **Menu → Syllabus Tracker**. Add only:
- Subject
- Chapter Name
- Total Lectures

Then click **Download Printable PDF**.

The PDF is **A4 landscape (297 × 210 mm)** and is designed for offline printing. Each chapter has a lecture tracker laid out as:

`□ L1   □ L2   □ L3 ...`

and separate empty checkboxes for JM Lec, Adv Lec, MBBS, OPP, HW, Module, PYQ, Adv Prob, R1, R2 and R3.

Print the PDF and tick it manually with a pen/pencil.
